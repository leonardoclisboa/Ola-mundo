# 🌍 Olá, Mundo! | Hello, World!

Bem-vindo(a) ao meu primeiro repositório no Git e GitHub. 

Este espaço foi criado para documentar minha jornada de aprendizado, armazenando projetos, códigos e anotações dos meus estudos em programação. Como tecnólogo em Análise e Desenvolvimento de Sistemas, utilizo este repositório para consolidar conceitos, testar novas ferramentas e registrar minha evolução prática na área de tecnologia.

## 🚀 O que você encontrará aqui

*   **Fundamentos:** Exercícios práticos e conceitos básicos de lógica de programação.
*   **Projetos de Estudo:** Aplicações desenvolvidas para testar novas linguagens e frameworks.
*   **Anotações:** Resumos teóricos e *snippets* de código úteis.

## 🛠️ Tecnologias e Ferramentas em Estudo

*   **Controle de Versão:** Git & GitHub
*   **Linguagens:** Python, C, mySQL, HTML e CSS

## 📂 Como navegar
Os arquivos estão divididos em pastas por assunto ou linguagem para facilitar a consulta. Sinta-se à vontade para explorar os códigos e sugerir melhorias.
